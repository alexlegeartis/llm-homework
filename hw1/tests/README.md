# Технические проверки кода

В [`test_homework.py`](test_homework.py) находятся 15 тестов на стандартном `unittest`. Они помогают обнаруживать ошибки при изменении кода. Отдельную папку с unit-тестами условие не требует; для запуска предсказаний она не нужна.

## Что проверяется

| Область | Примеры проверок |
| --- | --- |
| Формат и оценка | Фактические ID вариантов, точное совпадение наборов, правила отказа и ссылок, последствия ошибок формата и превышения лимитов. |
| Контекст и поиск | Бюджет входных токенов, сохранение находок по разным запросам, добавление продолжения и остановка перед следующей теоремой. |
| Клиент API | Заголовки запросов, учёт токенов, перевод A–F обратно в исходные ID, сохранение причины отказа. |
| Математическая запись | Нормализация LaTeX, исправление JSON-экранирования, сохранение исходного обоснования при удалении отдельных фраз о невыбранных вариантах, извлечение сопряжения, дробей, факториалов и корней из PDF. |

Ответы API в тестах имитируются: сеть, запущенный Qwen, GPU и ключ не нужны. Проверка PDF использует настоящий учебник из `homework_01_rag/data/textbook.pdf`; если его нет, только этот тест будет пропущен.

## Запуск

Из `hw1/`, в окружении с установленными `requirements.txt`:

```bash
python -m unittest discover -s tests -v
```

Чтобы выполнить также проверку PDF, предварительно запустите `python prepare_data.py` по [основной инструкции](../#воспроизведение-из-исходников).

Для оценки математических ответов используются отдельные [эксперименты с Qwen](../experiments/) на 15 вопросах из условия и восьми своих вопросах.
