# Сохранённые результаты экспериментов

Здесь находятся ответы Qwen и журналы пяти прогонов на одних и тех же 15 dev-вопросах. Сводная таблица — [`../experiments.csv`](../experiments.csv), разбор результатов и ограничений — в [отчёте](../report.md).

## Папки конфигураций

| Папка | Что запускалось |
| --- | --- |
| [`no_context/`](no_context/) | Qwen без фрагментов учебника. Оцениваются выбранные варианты; `Q` для этой конфигурации не вычисляется. |
| [`baseline/`](baseline/) | Простой RAG: один BM25-поиск по вопросу и вариантам, до трёх блоков, один вызов Qwen. |
| [`final/`](final/) | Итоговый RAG: расширение запросов, до четырёх основных блоков, продолжения и ссылки на формулы, один вызов Qwen. |
| [`without_expansion/`](without_expansion/) | Абляция: итоговая система без словарного расширения запросов. |
| [`without_neighbors/`](without_neighbors/) | Абляция: итоговая система без добавления соседей и переходов по номерам формул. |

## Файлы внутри каждого прогона

| Файл | Содержимое |
| --- | --- |
| `config.json` | Настройки конкретного прогона; ссылаются на общий `../../runtime.json`. |
| `answers.jsonl` | По одному ответу на вопрос: варианты, отказ, краткое обоснование и ID источников. |
| `trace.jsonl` | Найденные и отправленные блоки, поисковые запросы при расширении, фактические токены API, вызовы, время и сведения об ошибках. |
| `metrics.json` | Оценка выбранных вариантов и ссылок, результаты по вопросам и категориям, стоимость и проверка лимитов. |

В `../dev_answers.jsonl` и `../dev_trace.jsonl` сохранены копии соответствующих файлов из `final/`. Все параметры генерации общие и закреплены в `../runtime.json`.

## Как воспроизвести

Команда `python run_experiments.py ... --output-dir .` из `hw1/` создаёт эти подпапки и сводные файлы. Полная команда и подготовка окружения приведены в [основном README](../#оценка-и-эксперименты). Для пересчёта метрик из сохранённых ответов и trace предусмотрен `--summarize-only`; новые вызовы модели при этом не выполняются.

В условии обязательны сравнение трёх конфигураций, две абляции, `experiments.csv` и итоговые dev-файлы. Подробные файлы этой папки сохранены дополнительно, чтобы можно было проверить выводы отчёта. Они создаются кодом; ответы вручную не исправляются. Эффективность здесь рассчитана относительно собственного baseline, поскольку официальный `C_ref` не предоставлен.
