# Сохранённые результаты экспериментов

Здесь находятся ответы Qwen и отладочные файлы прогонов на двух наборах вопросов. Результаты на 15 вопросах из условия сведены в [`../experiments.csv`](../experiments.csv), на восьми подготовленных мною вопросах в [`own.csv`](own.csv). Метод и выводы приведены в [отчёте](../report.md).

## Папки прогонов

| Папка | Вопросы | Как получены ответы |
| --- | --- | --- |
| [`no_context/`](no_context/) | 15 из условия | Qwen получает только вопрос и варианты ответа. |
| [`baseline/`](baseline/) | 15 из условия | Один поиск BM25, до трёх фрагментов, один вызов Qwen. |
| [`final/`](final/) | 15 из условия | RAG со словарём расширения запросов, соседними фрагментами и фрагментами по номерам формул. |
| [`without_expansion/`](without_expansion/) | 15 из условия | Тот же RAG с отключённым словарём. |
| [`without_neighbors/`](without_neighbors/) | 15 из условия | Тот же RAG без добавления соседних фрагментов и переходов по номерам формул. |
| [`own_final/`](own_final/) | 8 своих | RAG со словарём и расширением контекста, с теми же настройками поиска и генерации, что в `final/`. |
| [`own_without_expansion/`](own_without_expansion/) | 8 своих | Тот же RAG с отключённым словарём. |

[`own_metadata.json`](own_metadata.json) содержит оборудование и параметры дополнительного прогона, контрольные суммы кода и входных файлов.

Пять папок на вопросах из условия содержат полное сравнение на [версии d8a4f03](https://github.com/alexlegeartis/llm-homework/tree/d8a4f03/hw1). Два прогона на своих вопросах используют ту же инструкцию из [версии 6fbf29e](https://github.com/alexlegeartis/llm-homework/tree/6fbf29e/hw1). Параметры генерации одинаковы. Прежние результаты с первой инструкцией доступны в [истории репозитория](https://github.com/alexlegeartis/llm-homework/tree/acc565a/hw1/experiments).

После сравнения уточнены требования к ответу и возвращён обычный порядок полей JSON. Отдельный прогон основного RAG на 15 вопросах с инструкцией из [версии 6d3262f](https://github.com/alexlegeartis/llm-homework/tree/6d3262f/hw1) сохранён в [`../dev_answers.jsonl`](../dev_answers.jsonl) и [`../dev_trace.jsonl`](../dev_trace.jsonl). Пять папок сравнения сохранены вместе с исходной общей инструкцией.

[`../run_metadata.json`](../run_metadata.json) содержит версии генерации и обработки обоснований, оборудование, контрольные суммы и метрики отдельного контрольного прогона. Исходные обоснования при удалении лишних предложений сохранены в [`../dev_trace.jsonl`](../dev_trace.jsonl). Вложенное поле `comparison` содержит метаданные сравнения пяти вариантов. Для своих вопросов аналогичные сведения находятся в [`own_metadata.json`](own_metadata.json).

## Файлы внутри каждого прогона

| Файл | Содержимое |
| --- | --- |
| `config.json` | Настройки конкретного прогона, ссылаются на общий `../../runtime.json`. |
| `answers.jsonl` | По одному ответу на вопрос: варианты, отказ, краткое обоснование и ID источников. |
| `trace.jsonl` | Найденные и отправленные блоки, поисковые запросы при расширении, фактические токены API, вызовы, время и сведения об ошибках. |
| `metrics.json` | Оценка выбранных вариантов и ссылок, результаты по вопросам и категориям, стоимость и проверка лимитов. |

## Как воспроизвести

[Команды запуска и пересчёта метрик](../#оценка-и-эксперименты) приведены в основном README. `run_experiments.py` создаёт подпапки и сводные файлы в каталоге, указанном через `--output-dir`.

Для двух прогонов на восьми своих вопросах из `hw1/`:

```bash
python run_experiments.py --index index --questions own_questions.jsonl --gold own_gold.jsonl --config config.json --output-dir .cache/own-results --names final without_expansion
```

При этом API Qwen должен быть запущен и его переменные окружения заданы по основному README. На Colab тот же запуск выполняет пресет [`own.json`](../colab/jobs/own.json). На VM результаты находятся в `/content/out/own/experiments/final/` и `/content/out/own/experiments/without_expansion/`. Сюда они скопированы как `own_final/` и `own_without_expansion/`, чтобы сохранить оба набора в одной папке результатов.

Подробные результаты сохранены дополнительно для проверки выводов отчёта. Методика сравнения, параметры генерации, локальные оценки и их ограничения описаны в [разделе об экспериментах](../report.md#эксперименты).
