# Код решения ДЗ 1

[Карта всего задания и запуск](../) находятся в родительском каталоге `hw1/`.

## Модули

| Файл | Что делает |
| --- | --- |
| [`pdf_text.py`](pdf_text.py) | Извлекает текст из PDF, восстанавливает математические символы и расположение формул, формирует блоки корпуса. |
| [`prepare_data.py`](prepare_data.py) | Скачивает и проверяет PDF, вызывает извлечение, преобразует исходные QA в dev-набор и создаёт авторские вопросы с эталонами. |
| [`retrieval.py`](retrieval.py) | Нормализует слова и формулы, строит BM25-индекс, расширяет запросы словарём, находит основные блоки и продолжения. |
| [`build_index.py`](build_index.py) | CLI сборки индекса и измерение времени, RAM и размера результата. |
| [`predict.py`](predict.py) | Формирует запрос с фрагментами в пределах бюджета, вызывает Qwen API, проверяет формат и сохраняет полный ответ с trace. |
| [`evaluate.py`](evaluate.py) | Проверяет формат и лимиты, оценивает варианты, отказы, ссылки и стоимость по формулам задания. |
| [`run_experiments.py`](run_experiments.py) | Запускает три основные конфигурации и две абляции, сохраняет результаты и собирает сводную таблицу. |
| [`common.py`](common.py) | Общие функции чтения JSONL и конфигурации, определение путей и измерение памяти. |
| [`__init__.py`](__init__.py) | Обозначает каталог как Python-пакет. |

Одноимённые скрипты на уровень выше импортируют `main()` из этих модулей. Они сохраняют команды запуска из условия; основная логика находится здесь. Отдельный `../prepare_models.py` скачивает закреплённый токенизатор.

- [`materials/tfkp_15_qa.md`](materials/tfkp_15_qa.md) — исходные 15 QA-пар преподавателя.
